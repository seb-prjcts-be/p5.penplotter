03 · Sketch to pen

Direct plot

Every plot.… call draws on the canvas and is remembered for the plotter. plot.go() sends it to an iDraw HSE / A2 — no SVG in between. Use Chrome or Edge, and park the carriage in the home corner first.

Core snippet
plot = p.createPlot({ x: 80, y: 150, width: 80 });   // mm on the bed
plot.rect(10, 10, 380, 230);
plot.polyline(points);
if (p.key === "p") plot.go();

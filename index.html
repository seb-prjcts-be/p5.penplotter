Two Libraries

This is the small one, the one you use in your sketch. Behind it sits the engine, which does the thinking. You only ever see this one.

  1. thisp5.penplotter

    What you use. Three commands in p5.js, nothing more. You draw as you always do, with plot. in front, and plot.go() sends your drawing to the pen. Take this if you sketch in p5.js.

  2. enginevanilla.penplotter

    What does the thinking. It knows how big your sheet is, in millimetres. It tidies the drawing up, works out the shortest route for the pen, tells you how long the plot will take, and talks to the machine. Plain JavaScript, no p5.js. You only need it on its own if you draw without p5. vanilla.penplotter →

Three Commands

p5.penplotter gives your sketch three new commands. All the thinking happens in the engine, so when something is fixed there, it is fixed for everyone at once.

  1. 01createPlot()

    The one you will use. It gives you plot. Every plot.line(), plot.circle() and so on draws on your canvas as always, and remembers the shape for the plotter. plot.go() sends the drawing to the pen; plot.stop() lifts the pen and stops.

  2. 02createPlotterEngine()

    For when you want to talk to the engine yourself: several pens, layers, or a file for another machine. Your canvas becomes the sheet. Most sketches never need this.

  3. 03drawPlotPlan()

    Shows you what the machine will actually do: the order it will draw in, the lines it will draw backwards, where it will start a circle. Good for seeing why the plot takes less time than your sketch would suggest.

No Surprises

You tell p5.penplotter which p5 and which engine to use, in your own code, where you can see it. That is three lines more than most libraries ask. It is also why a sketch you make this year still works next year, when versions have moved on.

import { PlotterEngine } from "vanilla.penplotter";
import * as Ebb from "vanilla.penplotter/driver/ebb";
import { installP5Penplotter } from "p5.penplotter";

installP5Penplotter(p5, PlotterEngine, { driver: Ebb });

let plot;

function setup() {
  createCanvas(600, 600);
  plot = createPlot({ x: 147, y: 66, width: 300 });  // 300 mm wide on the bed
}

function draw() {
  background(255);
  plot.clear();
  plot.circle(300, 300, 400);
}

function keyPressed() {
  if (key === "p") plot.go();   // to the pen
}
plot. in front, p to plot

Get Started

Put the three lines in your sketch. Write plot. in front of the shapes that should go on paper. Press P.

function setup() { createCanvas(600, 600); plot = createPlot({ width: 200 }); // 200 mm wide on the bed } function draw() { plot.clear(); plot.line(40, 300, 560, 300); plot.circle(300, 300, 240); } function keyPressed() { if (key === "p") plot.go(); }

Two Libraries

The p5 face, and the engine behind it. This one is the face; the engine does the work.

  1. thisp5.penplotter

    Three methods on p5.js, and nothing else. You draw as you always do, with plot. in front, and plot.go() sends the frame to the pen. Take it if you sketch in p5.js.

  2. enginevanilla.penplotter

    Where the work happens: geometry in millimetres, the optimizer, the route planner, the time estimate and the machine driver. Plain JavaScript, no p5.js. Take it on its own if you draw with other code. vanilla.penplotter →

a deliberately small bridge

Three Methods

The adapter adds three methods to the p5 prototype. Everything else lives in the engine, and a bug in the pipeline is fixed there, once, for both libraries.

  1. 01createPlot()

    The one you will use most. Every plot.… call draws on the canvas and is remembered for the plotter; plot.go() sends it, plot.stop() lifts the pen.

  2. 02createPlotterEngine()

    The bare engine with the canvas size as its page, when you want to talk to it directly: layers, pens, exports.

  3. 03drawPlotPlan()

    Draws the plan as the machine will draw it: the real order, reversed paths, moved seams. Useful to see what the planner did with your sketch.

no hidden dependency

Explicit Install

You hand the adapter the p5 constructor and the engine class, so versions and loading order stay in plain sight. It sounds fussy; it is what keeps a sketch working next year.

import { PlotterEngine } from "vanilla.penplotter";
import * as Ebb from "vanilla.penplotter/driver/ebb";
import { installP5Penplotter } from "p5.penplotter";

installP5Penplotter(p5, PlotterEngine, { driver: Ebb });

let plot;

function setup() {
  createCanvas(600, 600);
  plot = createPlot({ x: 147, y: 66, width: 300 });  // 300 mm wide on the bed
}

function draw() {
  background(255);
  plot.clear();
  plot.circle(300, 300, 400);
}

function keyPressed() {
  if (key === "p") plot.go();   // to the pen
}
plot. in front, p to plot

Get Started

Install the adapter in your sketch. Put plot. in front of the shapes that should reach paper. Press P.

function setup() { createCanvas(600, 600); plot = createPlot({ width: 200 }); // 200 mm wide on the bed } function draw() { plot.clear(); plot.line(40, 300, 560, 300); plot.circle(300, 300, 240); } function keyPressed() { if (key === "p") plot.go(); }

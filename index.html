Sketch.
Then plot.

You sketch in p5.js the way you always do. Write plot.line() instead of line() and the same line is drawn on the canvas and remembered in millimetres. Press a key, and the last frame goes to the plotter. No SVG, no vpype, no Inkscape in between.

Two libraries, one direction

The p5 face,
and the engine behind it.

  1. thisp5.penplotter

    Three methods on p5.js, and nothing else. You draw as you always do, with plot. in front, and plot.go() sends the frame to the pen. Take this if you sketch in p5.js.

  2. enginevanilla.penplotter

    Where the work happens: geometry in millimetres, the optimizer, the route planner, the time estimate and the machine driver. Plain JavaScript, no p5.js. Take it on its own if you draw with your own code, or want to build your own layer on it. vanilla.penplotter →

A deliberately small bridge

Three p5 methods.
One real engine.

  1. 01createPlot()

    The one you will use most. Every plot.… call draws on the canvas and is remembered for the plotter; plot.go() sends it, plot.stop() lifts the pen. Direct plot →

  2. 02createPlotterEngine()

    The bare engine with the canvas size as its page, when you want to talk to it directly: layers, pens, exports.

  3. 03drawPlotPlan()

    Draws the plan as the machine will draw it: the real order, reversed paths, moved seams. Useful to see what the planner did with your sketch.

  4. Corevanilla.penplotter

    Owns everything else. A bug in the pipeline is fixed there, once, for both libraries.

Explicit installation

No hidden
dependency.

The adapter is handed the p5 constructor and the engine class by you, so versions and loading order stay in plain sight. It sounds fussy; it is the thing that keeps a sketch working next year.

import { PlotterEngine } from "vanilla.penplotter";
import * as Ebb from "vanilla.penplotter/driver/ebb";
import { installP5Penplotter } from "p5.penplotter";

installP5Penplotter(p5, PlotterEngine, { driver: Ebb });

let plot;

function setup() {
  createCanvas(600, 600);
  plot = createPlot({ x: 147, y: 66, width: 300 });  // 300 mm wide on the bed
}

function draw() {
  background(255);
  plot.clear();
  plot.circle(300, 300, 400);
}

function keyPressed() {
  if (key === "p") plot.go();   // to the pen
}

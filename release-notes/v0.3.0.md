# p5.penplotter v0.3.0

2026-10-05

Adds automatic EBB and DrawCore recognition when you connect. The bundle includes vanilla.penplotter 0.5.0 and both drivers. Your drawing calls and plot.go() stay the same.

Adds DrawCore settings to createPlot(): machine bounds, pen Z positions, feed rates and axis directions. Setup shows the values used for the small A3 H test. Paper size still sets the sheet; it does not select the machine.

Adds an A3 H test page. Read the controller, try pen up, set the XY work origin and check the 1 mm moves before drawing a short line. The page can save its command log and runs without Inkscape.

The development bundle was physically tested on an A3 H with DrawCore V2.09 on 2026-10-05. The recorded tests cover a 10 mm line and square, pen movement, one pen-up direction test and return to the origin. The release bundle is checked by the automatic tests; it has not had a separate physical run. Larger drawings and stopping during motion remain to be tested.

DrawCore stop requests feed-hold. Queued movements can remain paused and the pen can remain down. Object-by-object sessions and automatic resume are not implemented for DrawCore. EBB sessions remain available.

Validation: adapter and core tests, serial simulations, repeatable bundle builds, comparison with adapter 0.2.2, all nine sketches in Chromium, and module, classic and instance startup. Existing Web Editor copies and old release tags are retained; those copies do not acquire this version automatically.

# p5.penplotter v0.2.2

In deze versie werk ik de voorbeelden en de presentatie van p5.penplotter bij.

- De CDN-startcode vraagt de actuele `main`-commits op en laadt de core en driver van dezelfde commit. De sketch wacht tot de libraries klaarstaan.
- Op de voorbeeldpagina's toon ik alleen het moduleblok voor `index.html`. Dat blok komt rechtstreeks uit het bijbehorende CDN-voorbeeld.
- Ik voeg de nieuwe geanimeerde hero toe aan de homepage.
- De automatische tests controleren de CDN-startvolgorde, versieconsistentie en het gedrag bij een mislukte commitlookup.

De correctie voor de voortijdige bewegings-time-out staat in de bijbehorende vanilla.penplotter-driver op `main`. Daar bewaakt een regressietest lange bewegingen gevolgd door korte commando's in een volle controllerwachtrij. Deze adapterrelease bevat de core en driver nog niet als bundel.

De lokale tests voor beide libraries slagen. De time-outcorrectie is met een gesimuleerde controller gecontroleerd; een nieuwe fysieke plottertest is nog niet bevestigd.

Voor v0.2.5 wil ik de CDN-koppeling verder optimaliseren, zodat de verbinding tussen adapter, core en driver in de library zelf wordt geregeld en de gebruiker minder laadcode nodig heeft. Tot die tijd halen de CDN-voorbeelden de actuele code op. Voor een project dat ongewijzigd moet blijven, bewaar ik de exacte commit-URLs die de console meldt.

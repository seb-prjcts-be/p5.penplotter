let the grid come apart

Molnár grid

Ten rows of nested squares. The top row is exact; each row down, the squares drift and turn a little more, until the bottom row has come apart. Try another seed to change the arrangement. The drawing is a plain global-mode sketch; its library imports are in index.html.

let disorder = row / (n - 1);
let angle = random(-1, 1) * disorder * QUARTER_PI;
plot.polygon(corners(cx + dx, cy + dy, radius, angle));

Calibration sheet

What your pen does on your paper: a 100 mm ruler, hatch and cross-hatch scales down to 0.8 mm, stipple densities, circles from 2 to 40 mm and line pairs from 0.3 mm apart. Plot it once per pen and keep the sheet.

[6, 4, 3, 2, 1.5, 1.2, 1, 0.8].forEach((spacing, i) => {
plot.hatch(cellAt(20 + i * 22, 45, 18), spacing, QUARTER_PI);

Wave field

Two waves, one per axis, give every point a direction; sixty lines follow it until they leave the frame. The seed picks the wave shape: different fields from different seeds.

const angle = (Waves.wave(x * 0.012, { wave: shape, t: 0 })
+ Waves.wave(y * 0.012 + 3, { wave: shape, t: 0 })) * PI;
x += cos(angle) * 2.4;
y += sin(angle) * 2.4;

three wheels, one unbroken line

Spirograph

Three hypotrochoids around one centre; the seed picks the gear ratios. Each curve is one unbroken polyline, with no pen lift within the curve.

const t = (i / steps) * TWO_PI * turns;
points.push([cx + (R - r) * cos(t) + d * cos(((R - r) / r) * t),
cy + (R - r) * sin(t) - d * sin(((R - r) / r) * t)]);
plot.polyline(points);

a triangle nobody drew, dot by dot

Chaos game

One point jumps halfway to a random corner and leaves a dot; after a few hundred dots the Sierpinski triangle is there. Calculate 25 dots, plot them and wait, then calculate the next group. Each job returns home. The screen demo shows the sequence without a machine.

const c = random(corners);
p.x = (p.x + c[0]) / 2;
p.y = (p.y + c[1]) / 2;
plot.point(p.x, p.y);
// nextDots records 25 dots and returns false when finished.
plot.sequence(nextDots, { plan: { strategy: "drawn" } });

First plot

Create the core engine from a p5 canvas, build a hatched polygon and a circle, and draw the optimized plan back with p5: the same order and seams the machine would get.

const plot = createPlotterEngine();
plot.hatch(boundary, { spacing: 14, angle: Math.PI / 6 });
plot.circle(324, 374, 126);
drawRoute(plot.plan());

twenty-four rows of one wave

Wave plot

Sample a wave formula into 24 rows of points and inspect the planned route. The adapter passes the sampled points to the engine.

const waveY = Waves.wave(x + row * 7, { wave: waveSeed, t: 0, amplitude: 22, frequency: 0.045 });
points.push({ x, y: 86 + row * 24 + waveY });
plot.polyline(points);

createPlotterEngine() · drawPlotPlan()

First plot

Create the core engine from a p5 canvas, build a hatched polygon and a circle, and draw the optimized plan back with p5: the same order and seams the machine would get.

const plot = p.createPlotterEngine();
plot.hatch(boundary, { spacing: 14, angle: Math.PI / 6 });
plot.circle(324, 374, 126);
p.drawPlotPlan(plot.plan());

p5.waves · Waves.wave() · plot.polyline()

Wave plot

Sample one of 34 wave formulas into 24 rows of points and inspect the planned route. p5.waves returns numbers; the adapter passes their points to the engine.

const waveY = Waves.wave(x + row * 7, { wave: waveSeed, t: 0, amplitude: 22, frequency: 0.045 });
points.push({ x, y: 86 + row * 24 + waveY });
plot.polyline(points);

createPlot() · plot.go() · plot.stop()

Direct plot

Every plot.… call draws on the canvas and is remembered for the plotter. Press P and the last frame goes to an iDraw HSE / A2, no SVG in between.

plot = p.createPlot({ x: 80, y: 150, width: 80 });   // mm on the bed
plot.rect(10, 10, 380, 230);
plot.polyline(points);
if (p.key === "p") plot.go();

global mode · random() · plot.polygon()

Molnár grid

Ten rows of nested squares. The top row is exact; each row down, the squares drift and turn a little more, until the bottom row has come apart. One seed, one rule, a plain global-mode sketch with no imports.

let disorder = row / (n - 1);
let angle = random(-1, 1) * disorder * QUARTER_PI;
plot.polygon(corners(cx + dx, cy + dy, radius, angle));

plot.hatch() · plot.crossHatch() · plot.stipple() · plot.circle()

Calibration sheet

What your pen does on your paper: a 100 mm ruler, hatch and cross-hatch scales down to 0.8 mm, stipple densities, circles from 2 to 40 mm and line pairs from 0.3 mm apart. Only physical variables. Plot it once per pen and keep the sheet.

[6, 4, 3, 2, 1.5, 1.2, 1, 0.8].forEach((spacing, i) => {
  plot.hatch(cellAt(20 + i * 22, 45, 18), spacing, QUARTER_PI);
});

p5.waves · streamlines · plot.polyline()

Wave field

Two waves, one per axis, give every point a direction; sixty lines follow it until they leave the frame. The seed picks the wave shape: thirty-four fields in one sketch.

const angle = (Waves.wave(x * 0.012, { wave: shape, t: 0 })
             + Waves.wave(y * 0.012 + 3, { wave: shape, t: 0 })) * PI;
x += cos(angle) * 2.4;
y += sin(angle) * 2.4;

hypotrochoids · one polyline each

Spirograph

Three hypotrochoids around one centre; the seed picks the gear ratios. Each curve is one unbroken polyline, so the pen never lifts until it closes.

const t = (i / steps) * TWO_PI * turns;
points.push([cx + (R - r) * cos(t) + d * cos(((R - r) / r) * t),
             cy + (R - r) * sin(t) - d * sin(((R - r) / r) * t)]);
plot.polyline(points);

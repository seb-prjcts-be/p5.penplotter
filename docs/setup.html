Setup

Install the library, check that it loads, then check the plotter connection.

1. Prepare the editor

Open a sketch in the p5.js Web Editor. Replace its index.html with this file. For a local project, serve the folder through localhost.

The imports use tested source commits. Keep them in index.html; keep sketch.js as a normal script.

index.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>penplotter start</title>
  <script src="https://cdn.jsdelivr.net/npm/p5@2.2.2/lib/p5.js"></script>
  <script type="module">
    import { PlotterEngine } from "https://cdn.jsdelivr.net/gh/seb-prjcts-be/vanilla.penplotter@4880b41b911ede36b391e2924a4949b27bdb2378/vanilla.penplotter.js";
    import * as Ebb from "https://cdn.jsdelivr.net/gh/seb-prjcts-be/vanilla.penplotter@4880b41b911ede36b391e2924a4949b27bdb2378/src/driver/ebb.js";
    import { installP5Penplotter } from "https://cdn.jsdelivr.net/gh/seb-prjcts-be/p5.penplotter@b495d269a0f38d8e5fd83b3368a483d0fe50d006/p5.penplotter.js";
    installP5Penplotter(p5, PlotterEngine, { driver: Ebb });
  </script>
  <script src="sketch.js"></script>
</head>
<body>
</body>
</html>

2. Check the installation

Replace sketch.js with this small test and press Run.

sketch.js

let plot;

function setup() {
  createCanvas(400, 250);
  plot = createPlot({ paper: "A4", margin: 12, width: 120 });
  noLoop();
}

function draw() {
  background(255);
  stroke(0);
  plot.line(80, 125, 320, 125);
}

A horizontal line should appear without an error in the console. This checks p5.js and the adapter. It does not open a USB connection.

3. Check the plotter connection

For direct plotting, use Chrome or Edge with the editor, HTTPS or localhost. Connect the plotter by USB. The supplied imports include the EBB driver for the tested iDraw HSE / A2.

Park the carriage at the physical origin

In my setup, viewed as in the diagram below, the carriage starts at the bottom-left corner. Positive X runs up the long rail (594 mm); positive Y runs to the right across the bed (432 mm). The paper preview turns those axes into a coordinate view: (0,0) at top left, X to the right and Y down. These are two views of the same bed.

The machine does not detect its position. The driver assumes that the carriage starts at (0,0). Moving it to another corner changes the physical starting point, but does not reverse the motor directions. Positive coordinates can then send the carriage towards the wrong edge. paperX/paperY move paper within the existing coordinates; they do not change the machine origin. The bounds check verifies the plan, not the physical carriage position.

For this test, place A4 paper in landscape at X = 148.5 mm, Y = 111 mm in the bed coordinates. The 120 × 75 mm canvas area is centred on that sheet. The Guide explains paper size and placement.

Add plot.go(); after plot.line() in the test. Run the sketch, then click the drawing and choose the plotter in the port list. It should draw one 72 mm line and return home. Click again to request a stop. After a stop or error, park the carriage at the physical origin before another plot.

If the installation fails

  • createPlot is not defined: check that the imports loaded and that sketch.js is a normal script. Call createPlot() inside setup().
  • p5 is not defined: put the p5 script before the imports and check its network request.
  • No serial port list: use Chrome or Edge on HTTPS or localhost, then click the drawing.
  • An older version keeps appearing: reload with Ctrl+F5.

Continue with the Guide to learn the drawing calls and the two ways to plot.

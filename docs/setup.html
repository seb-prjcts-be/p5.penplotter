Setup

1. Prepare the editor

Open a sketch in the p5.js Web Editor. Replace its index.html with this file. For a local project, serve the folder through localhost.

index.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>penplotter start</title>
  <script src="https://cdn.jsdelivr.net/npm/p5@2.2.2/lib/p5.js"></script>
  <script type="module">
    import { PlotterEngine } from "https://cdn.jsdelivr.net/gh/seb-prjcts-be/vanilla.penplotter@4880b41b911ede36b391e2924a4949b27bdb2378/vanilla.penplotter.js";
    import * as Ebb from "https://cdn.jsdelivr.net/gh/seb-prjcts-be/vanilla.penplotter@4880b41b911ede36b391e2924a4949b27bdb2378/src/driver/ebb.js";
    import { installP5Penplotter } from "https://cdn.jsdelivr.net/gh/seb-prjcts-be/p5.penplotter@b495d269a0f38d8e5fd83b3368a483d0fe50d006/p5.penplotter.js";
    installP5Penplotter(p5, PlotterEngine, { driver: Ebb });
  </script>
  <script src="sketch.js"></script>
</head>
<body>
</body>
</html>

2. Draw a line on screen

Replace sketch.js with this small test and press Run.

sketch.js

let plot;

function setup() {
  createCanvas(400, 250);
  plot = createPlot({
    paper: "A2",
    paperX: 0,
    paperY: 0,
    margin: 12,
    x: 12,
    y: 12,
    width: 120
  });
  noLoop();
}

function draw() {
  background(255);
  stroke(0);
  plot.line(80, 125, 320, 125);
}

You should see a horizontal line. The plotter does not move yet.

3. Plot the same line on paper

Use Chrome or Edge. Connect the plotter by USB and switch it on.

Prepare the paper and pen

On my iDraw HSE / A2, the starting corner is bottom left when the long rails run away from you. With the motors off, move the carriage to that corner. The driver takes this position as zero; the machine does not find it automatically.

Use the paper already on the machine. Set paper in the sketch to its format. Set paperX and paperY to the paper corner's distance from the machine origin, in millimetres along each axis. Both are zero when that corner is at the origin. Set x and y to those distances plus the margin to place the drawing at the paper corner. See Paper and placement for the placement options.

If your machine has a different starting corner or motor direction, confirm its origin before running this test. Moving the carriage to another corner does not change the driver's directions.

Start the plot

  1. Add plot.go(); immediately after plot.line(80, 125, 320, 125); in the sketch above.
  2. Press Run. The line appears on screen again.
  3. Click the drawing. Select the plotter in the browser's port list and click Connect.

The pen should draw a 72 mm line in the drawing area near the paper corner, then return to the machine origin.

Click the drawing again to stop. After a stop or error, switch off the motors and return the carriage to the starting corner before trying again.

If the installation fails

  • createPlot is not defined: check that the imports loaded and that sketch.js is a normal script. Call createPlot() inside setup().
  • p5 is not defined: put the p5 script before the imports and check its network request.
  • No serial port list: use Chrome or Edge on HTTPS or localhost, then click the drawing.
  • An older version keeps appearing: reload with Ctrl+F5.

Continue with the Guide to learn the drawing calls and the two ways to plot.
